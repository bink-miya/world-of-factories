はじめに#

前回の記事では、インフレによって「どこで利益が発生するのか」という構造を整理した。

ただ、現実には同じ業界に属していても、

  • 利益を伸ばす企業
  • 利益を圧迫される企業

がはっきりと分かれる。

この差は、業界の違いだけでは説明できない。

本記事では、その違いを企業の構造という視点から整理する。

※本記事は投資助言を目的としたものではありません。企業を見るための構造的な視点を整理したものです。

なぜ同じ業界でも勝敗が分かれるのか#

同じ業界にいれば、同じような条件で戦っているように見える。

しかし実際には、企業ごとに次の3つが異なる。

  • コスト構造
  • 価格決定力
  • 意思決定の速さ

つまり、勝敗を分けているのは業界名ではなく、

「企業の内部構造」

である。

結論#

強い企業とは、単に有利なポジションにいる企業ではない。

環境変化を、そのまま利益に変換できる構造を持つ企業である。

具体的には、

  • コスト上昇を吸収できる構造を持つか
  • 価格に転嫁できる構造を持つか
  • 変化に対して迅速に動ける構造を持つか

この3つのいずれか、あるいは複数を備えている企業が強い。

逆に、環境変化を「コスト」としてしか受け取れない企業は弱い。

企業の勝敗を分ける3つの構造#

  graph TD
    A[企業の構造] --> B[コスト構造]
    A --> C[価格決定力]
    A --> D[意思決定の速さ]

    B --> B1[固定費が軽い]
    B --> B2[自動化・省人化]
    B --> B3[古い設備が少ない]

    C --> C1[値上げできる]
    C --> C2[代替が効きにくい]
    C --> C3[取引先に依存しすぎない]

    D --> D1[判断が速い]
    D --> D2[階層が少ない]
    D --> D3[変化に対応できる]

① コスト構造：コスト上昇を吸収できるか#

インフレ時には、原材料費、燃料費、人件費などが上がる。

このとき強いのは、そうしたコスト上昇を受けても利益が崩れにくい企業である。

強い構造#

  • 固定費が軽い
  • 自動化が進んでいる
  • 省人化できている
  • 新しい設備で効率が高い

弱い構造#

  • 人手に依存している
  • 古い設備を抱えている
  • 固定費が重い
  • 過去の資産が負担になっている

見えてくること#

同じメーカーでも、
自動化が進んでいる企業と、人手依存の企業では、インフレ時の利益の出方がまったく違う。

② 価格決定力：値上げを通せるか#

コストが上がっても、それを販売価格に反映できる企業は強い。

逆に、価格を決められない企業は、コスト上昇を自分でかぶることになる。

強い構造#

  • ブランドがある
  • 必需品を扱っている
  • 代替が効きにくい
  • 顧客が離れにくい
  • 取引先に対して交渉力がある

弱い構造#

  • どこでも代替できる
  • 価格競争に巻き込まれやすい
  • 下請けで単価を決められない
  • 値上げするとすぐ失注する

見えてくること#

利益率を守れるかどうかは、
「何を売っているか」以上に、その価格を誰が決めているかで決まる。

③ 意思決定の速さ：変化に対応できるか#

インフレ環境では、調達、価格改定、投資判断、在庫戦略などを素早く変えられる企業が強い。

強い構造#

  • 組織階層が少ない
  • 現場に権限がある
  • 価格改定が速い
  • 調達先の見直しができる
  • 変化に対して経営判断が早い

弱い構造#

  • 承認に時間がかかる
  • 前例主義が強い
  • 本社判断が遅い
  • 価格改定が後手に回る
  • 環境変化への反応が遅い

見えてくること#

同じ大企業でも、
軽い組織は伸び、過去のやり方に縛られた組織は沈みやすい。

見分け方のフレーム#

企業を見るときは、以下の3つを確認すればよい。

  flowchart TD
    A[企業を見る] --> B[コストは誰が負担しているか]
    A --> C[価格は誰が決めているか]
    A --> D[意思決定はどこで止まるか]

    B --> B1[自社が吸収している]
    B --> B2[顧客に転嫁できている]
    B --> B3[仕入先と分担できている]

    C --> C1[自社主導]
    C --> C2[市場主導]
    C --> C3[取引先主導]

    D --> D1[現場で動ける]
    D --> D2[本社集中]
    D --> D3[多層承認]

① コストは誰が負担しているか#

  • 自社が負担しているのか
  • 顧客に転嫁できているのか
  • 仕入先との力関係で調整できているのか

② 価格は誰が決めているか#

  • 自社が決められるのか
  • 市場価格に従うしかないのか
  • 大口取引先に決められているのか

③ 意思決定はどこで止まるか#

  • 現場が動けるのか
  • 本社承認が必要なのか
  • 複数階層で止まるのか

この3つを見れば、その企業が

「利益を出せる構造」なのか、
「利益を削られやすい構造」なのか

が見えてくる。

強い企業とは何か#

ここまでをまとめると、強い企業とは、

  • コスト上昇を吸収できる
  • 値上げを通せる
  • 変化に対して早く動ける

という3つのうち、少なくとも1つ、できれば複数を持つ企業である。

逆に弱い企業とは、

  • コスト上昇をそのまま受ける
  • 値上げできない
  • 意思決定が遅い

という構造を抱えた企業である。

本質#

インフレは企業を強くするわけではない。

もともと強い構造を持つ企業だけが、
その強さを結果として表に出す。

逆に、弱い構造を抱えた企業は、環境変化によってその弱さを表面化させる。

つまり、インフレとは単なる価格上昇ではなく、

企業の構造的な強さと弱さをあぶり出す現象

なのである。

まとめ#

同じ業界でも勝敗が分かれる理由は、企業の構造が違うからである。

見るべきなのは業界名ではない。

  • コスト構造
  • 価格決定力
  • 意思決定の速さ

この3つを見ることで、その企業が環境変化を利益に変えられるかどうかが見えてくる。

構造で詰まっている方へ

業務・IT・収益構造などで違和感がある場合、 構造を整理することで問題の本質が見えることがあります。
