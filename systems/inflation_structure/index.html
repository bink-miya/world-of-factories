はじめに#

日本でも物価上昇が続く中、「誰が儲かっているのか？」は見えにくいテーマです。

本記事では、身近な5つの分野を例に、インフレ時の利益構造を分解します。

国内生産の食品#

  graph LR
A[農家] --> B[卸売市場]
B --> C[スーパー]
C --> D[消費者]

強いところ#

  • 一部の大規模農家
  • 強いスーパー

弱いところ#

  • 小規模農家
  • 中間卸

理由#

  • 農家：規模が小さいと価格転嫁できずコスト増を吸収できない
  • 卸：仕入れ上昇と販売価格の板挟み
  • スーパー：規模が大きいほど価格決定力あり

輸入食品#

  graph LR
A[海外生産] --> B[商社]
B --> C[食品メーカー]
C --> D[小売]
D --> E[消費者]

強いところ#

  • 商社
  • 値上げできる食品メーカー

弱いところ#

  • 中小食品メーカー
  • 消費者

理由#

  • 商社：価格上昇をそのまま通せる
  • メーカー：ブランドがないと値上げ困難
  • 消費者：為替と原料高を直接負担

ガソリン#

  graph LR
A[原油] --> B[石油元売]
B --> C[ガソリンスタンド]
C --> D[消費者]

強いところ#

  • 資源保有者
  • 元売企業

弱いところ#

  • 消費者
  • 物流業者

理由#

  • 上流が価格を決定
  • 代替手段がなく、下流はコストを受け入れるしかない

生活雑貨#

  graph LR
A[原材料] --> B[メーカー]
B --> C[小売]
C --> D[消費者]

強いところ#

  • 原材料メーカー
  • ブランドメーカー

弱いところ#

  • 中小メーカー
  • 小売

理由#

  • 原材料：価格そのものを握る
  • ブランド：値上げできる
  • 小売：競争激しく価格転嫁しにくい

結論#

インフレで儲かるのは以下の3層です：

  • 上流（資源・原材料）
  • 流通強者（商社など）
  • 価格決定権を持つ企業

逆に弱いのは：

  • 中間業者
  • 労働集約産業
  • 消費者

本質#

インフレで儲かるのは、単純に「上流にいる企業」ではない。

確かに、資源や原材料を持つ企業は構造的に有利である。 しかし、それだけで勝敗が決まるわけではない。

実際には、

  • 同じメーカーでも、価格転嫁できる企業とできない企業がある
  • 同じ立場でも、コスト構造によって利益の出方が大きく変わる

つまり、この構造から見えてくるのは、

「どこにいるか」だけではなく、
「どういう構造でそこにいるか」が重要である

ということだ。

インフレは単なる価格上昇ではなく、

企業の構造的な強さと弱さをあぶり出す現象

とも言える。

では、この構造の中で、

  • なぜ同じ業界でも勝つ企業と負ける企業が分かれるのか
  • どのような構造を持つ企業が強いのか

については、別記事で整理する。
