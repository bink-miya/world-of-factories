なぜ同じ業界でも勝つ企業と負ける企業が分かれるのか？インフレ時代の企業構造の見方

はじめに 前回の記事では、インフレによって「どこで利益が発生するのか」という構造を整理した。 ただ、現実には同じ業界に属していても、 利益を伸ばす企業 利益を圧迫される企業 がはっきりと分かれる。 この差は、業界の違いだけでは説明できない。 本記事では、その違いを企業の構造という視点から整理する。 ※本記事は投資助言を目的としたものではありません。企業を見るための構造的な視点を整理したものです。 なぜ同じ業界でも勝敗が分かれるのか 同じ業界にいれば、同じような条件で戦っているように見える。 しかし実際には、企業ごとに次の3つが異なる。 コスト構造 価格決定力 意思決定の速さ つまり、勝敗を分けているのは業界名ではなく、 「企業の内部構造」 である。 結論 強い企業とは、単に有利なポジションにいる企業ではない。 環境変化を、そのまま利益に変換できる構造を持つ企業である。 具体的には、 コスト上昇を吸収できる構造を持つか 価格に転嫁できる構造を持つか 変化に対して迅速に動ける構造を持つか この3つのいずれか、あるいは複数を備えている企業が強い。 逆に、環境変化を「コスト」としてしか受け取れない企業は弱い。 企業の勝敗を分ける3つの構造 graph TD A[企業の構造] --> B[コスト構造] A --> C[価格決定力] A --> D[意思決定の速さ] B --> B1[固定費が軽い] B --> B2[自動化・省人化] B --> B3[古い設備が少ない] C --> C1[値上げできる] C --> C2[代替が効きにくい] C --> C3[取引先に依存しすぎない] D --> D1[判断が速い] D --> D2[階層が少ない] D --> D3[変化に対応できる] ① コスト構造：コスト上昇を吸収できるか インフレ時には、原材料費、燃料費、人件費などが上がる。 このとき強いのは、そうしたコスト上昇を受けても利益が崩れにくい企業である。 ...
