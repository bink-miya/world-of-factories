工場の統廃合は何で決まるのか？粗利/人と供給構造で読み解く再編の本質

工場の統廃合は何で決まるのか？ 同じ製品を複数の工場で作っている場合、 なぜ統廃合が起きるのか。 現場から見ると「なぜうちが？」になるが、 本社の判断基準は別にある。 この記事では、その判断基準を構造として整理する。 再編の起点は「粗利/人」 多くのケースで再編の起点になるのは、 一人当たりの売上総利益（粗利） である。 しかし実際には、それだけでは決まらない。 👉 供給構造（どこで作るか）も同時に見られている 粗利/人の正体 粗利/人は次の3つで決まる。 価格（付加価値） コスト（人・設備） 稼働率（需要） flowchart TD A["事業"] --> B["価格"] A --> C["コスト"] A --> D["稼働率"] B --> E["粗利/人"] C --> E D --> E もう一つの軸：「供給」 実際の再編では、もう一つ重要な軸がある。 👉 供給（Supply） 供給で見られるポイント 原料調達（港・輸送距離） 顧客への距離（物流コスト） 地政学リスク（例：中東） 在庫・リードタイム flowchart TD A["立地"] --> B["原料調達"] A --> C["物流"] A --> D["リスク"] B --> E["供給力"] C --> E D --> E なぜ供給が重要になるのか 粗利/人が同じでも、供給で差が出る。 例 港に近い工場 → 原料コスト低い 内陸工場 → 輸送コスト増 👉 同じ製品でも「構造」が違う ...
