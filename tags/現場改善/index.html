判断基準を数値化する方法【現場で使えるデータ活用の実践手順】

前回、「日本企業は主観で判断している」という話を書いた。 では実際に、どうすれば判断を数値化できるのか。 今回は現場で使える形で、 判断基準を数値化する具体的な手順を整理する。 ■ なぜ数値化が必要なのか 判断を数値化する目的はシンプルだ。 判断を揃える 再現性を持たせる データとして蓄積する つまり、 「人に依存しない意思決定」を作るためである。 ■ 手順①：まず「何を判断しているか」を分解する 最初にやるべきことは、判断そのものの分解である。 例えば品質判断。 「この製品はOKか？」では曖昧すぎる。 これを分解すると、 外観の傷 寸法誤差 機能テスト結果 といった要素に分かれる。 👉 ポイントは “判断を小さくすること” ■ 手順②：「言葉」を排除する 次にやるのは、曖昧な言葉を消すこと。 現場でよくある表現： 適切に 異常があれば 問題なければ これをそのまま使うと、必ずブレる。 例えば： 「適切な温度」→ 何℃か？ 「異常」→ どの値を超えたらか？ 👉 ポイントは 「誰が見ても同じ判断になる表現」にすること ■ 手順③：閾値（しきい値）を決める 数値化の核心はここである。 例えば： 不良率 → 3%を超えたら停止 温度 → 80℃以上で異常 振動 → 規定値の1.5倍でアラーム 重要なのは、 「グレーを残さないこと」 ■ 手順④：迷う部分は“段階化”する 現実には白黒つかないケースもある。 その場合は段階に分ける。 例： 正常 注意 異常 それぞれに数値を割り当てる。 👉 ポイントは 判断を“連続”ではなく“区切る”こと ■ 手順⑤：実際のデータと突き合わせる ここで初めてデータを使う。 ...
